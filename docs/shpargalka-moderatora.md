# Шпаргалка модератора admin.pro-body.kz

Источник: код pb-backend (ветка main-kz), 11.11.2026. Экран админки ещё не сверен вживую — названия кнопок уточним по скриншотам.

## Статусы анкеты (entityState)
| Статус | Что значит | Видна на сайте |
|---|---|---|
| payment_required | Анкета создана, размещение не оплачено («ждёт оплату») | нет |
| pending | Новая, ждёт одобрения админом («Входящие») | нет |
| updated | Рекламодатель отредактировал анкету, ждёт проверки | нет* |
| active | Активна | да |
| paused | Приостановлена (истёк срок услуги, сам рекламодатель или админ) | нет (страница 404) |
| declined | Отклонена, можно восстановить | нет |
| deleted | В корзине | нет |

*На сайте показываются только active (поиск отдаёт анкету только при active).

## Как анкета меняет статус
- Регистрация → payment_required → после оплаты → pending → админ одобряет → active.
- Рекламодатель правит анкету в кабинете → updated (если была pending — остаётся pending). Нужна повторная проверка.
- Истёк срок услуги → paused системой (actor = system). Это делает отдельный сервис, не pb-backend.
- Рекламодатель сам может нажать «Приостановить»/«Активировать» (не больше 3 пауз в сутки). Вакансии и спецпредложения ставятся на паузу вместе с анкетой.

## Что делает админ при смене статуса
Одна операция «изменить статус» + причина (если причину не указать: «Администратор изменил статус без указания причины»). Автоматически:
- запись в историю статусов (видна в карточке анкеты);
- **SMS рекламодателю на номер логина** (отправляется сразу, отменить нельзя):
  - active → «Ваша анкета одобрена…»
  - paused → «Ваша анкета приостановлена. По вопросам, обратитесь к администратору…» + все вакансии на паузу
  - declined → «Ваша анкета отклонена…»
  - deleted → «Ваша анкета удалена…»
- обновление данных в ИИ-поиске сайта.

## Другие действия админа в карточке анкеты
- Редактировать описание и программы (переводится на другие языки автоматически).
- Фото салона и мастеров: загрузить/удалить (удаление стирает файл из хранилища — необратимо).
- Пополнить баланс (ручное пополнение, источник «admin») / удалить пополнение.
- Верификация: на 30 дней, навсегда, продлить +30 дней, отменить.
- «Войти как пользователь» — открыть кабинет рекламодателя от его имени.

## Фильтры списка анкет
Статус, тип (салон/мастер), верификация (нет / на месяц+ / навсегда), PRO-подписка, рабочие дни, даты создания, поиск: цифры → по рабочему телефону анкеты, текст → по названию. На вкладке «Приостановленные» есть счётчики: всего приостановлено системой и сегодня.

## Правила модерации (наши)
- Любое изменение в админке — только после «да» Максата.
- Перед сменой статуса помнить: SMS уходит автоматически.
- Поиск по номеру ищет рабочий телефон анкеты, а не логин; логин и контактный номер могут отличаться.
