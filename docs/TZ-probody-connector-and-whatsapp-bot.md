# ТЗ: коннектор PRO-BODY.KZ для Claude + WhatsApp-бот регистрации

Версия 1 · 15.10.2026 · Делаем сами (Максат + Claude).

## Цель
1. **Коннектор (MCP-сервер, только чтение)** — Claude в чате и в запланированных задачах видит живые данные Probody: анкеты, оплаты, регистрации, трафик. Для отчётов, реактивации и контента.
2. **WhatsApp-бот** — отвечает рекламодателям и гостям в WhatsApp, помогает зарегистрироваться и выбрать продвижение, передаёт сложные вопросы человеку. Использует тот же слой данных.

## Часть 1. MCP-коннектор (read-only)

### Архитектура
```
Claude (claude.ai, коннектор) ──HTTPS + OAuth/Bearer──▶ probody-mcp (новый сервис)
                                                         │  только GET
                                                         ▼
                                              API pro-body.kz (существующий)
```
- Отдельный маленький сервис **probody-mcp** (Node.js/TypeScript, официальный MCP SDK, транспорт Streamable HTTP).
- Хостинг: рядом с основным сайтом на AWS (Lambda/контейнер) или Cloudflare Workers. Домен: `mcp.pro-body.kz` через Cloudflare.
- Ключ API pro-body.kz хранится **только в переменных окружения сервиса**, никогда в чате.
- Доступ к самому MCP: OAuth (как у Altegio) или длинный секретный токен в URL коннектора — на первом этапе достаточно токена + Cloudflare WAF (rate limit).
- **Только чтение.** Никаких методов, меняющих данные. Персональные данные (телефоны, ФИО) — маскировать по умолчанию (`+7 7** *** 12 34`), полные — отдельным инструментом только для владельца.

### Инструменты (tools)
| Инструмент | Что возвращает |
|---|---|
| `listings_summary` | Кол-во анкет по статусам (активна / пауза / на модерации / удалена), по городам, по типу (салон/мастер) |
| `listings_search` | Список анкет с фильтрами: статус, город, тип, VIP/PRO/ТОП, дата последней оплаты, «на паузе больше N дней» |
| `listing_get` | Карточка анкеты: статусы, услуги, цены, рейтинг, история оплат, дата регистрации, последняя активность |
| `payments_summary` | Выручка за период: по услугам (ТОП, VIP, PRO, верификация, акции, размещение), по городам, средний чек, новые vs повторные плательщики |
| `payments_list` | Платежи за период (сумма, услуга, анкета, способ оплаты) |
| `signups` | Регистрации за период, конверсия «регистрация → первая оплата» |
| `churn_candidates` | Анкеты, которые платили раньше и сейчас на паузе — с датой последней оплаты и суммой за всё время (для реактивации) |
| `traffic_summary` | Просмотры анкет, клики WhatsApp/звонок по анкетам и городам (если хранится в БД; иначе позже через GA4) |
| `ai_questions` | Последние вопросы гостей к ИИ на сайте (обезличенно) — для контента и FAQ |

Все инструменты: параметры `date_from`, `date_to`, `city`, пагинация `page/page_size`.

### Что нужно от Максата / разработчика API
1. Документация текущего API (Swagger/Postman или список эндпоинтов) и какие из них уже есть для админки.
2. Отдельный **read-only ключ** API (или сервисный пользователь с ролью «только чтение»).
3. Список статусов анкет и услуг как в базе (названия полей).
4. Решение по хостингу (AWS или Cloudflare Workers).

### Этапы
1. Каркас MCP-сервера + `listings_summary`, `payments_summary` → подключаем в Claude как коннектор, проверяем.
2. Остальные инструменты.
3. Еженедельный автоотчёт Claude по Probody (запланированная задача) и список реактивации.

## Часть 2. WhatsApp-бот регистрации и продаж

### Канал
- **WhatsApp Business Platform (Cloud API от Meta)** — официально, без риска бана. Номер — отдельный рабочий номер Probody (не личный).
- Шаблоны сообщений (для рассылок вне 24-часового окна) согласуются в Meta.

### Что умеет бот
**Для рекламодателей (салоны и мастера):**
- Объясняет, как работает платформа, цены на продвижение (ТОП, VIP, PRO, акции, вакансии), бонус −20% при регистрации.
- Ведёт по регистрации по шагам: тип (салон/мастер) → город → ссылка на регистрацию → помощь с заполнением анкеты (фото, цены, адрес на карте).
- Проверяет статус анкеты по номеру телефона: «Ваша анкета на паузе с 12.09 — активировать?» + ссылка на оплату.
- Реактивация: по шаблону пишет анкетам на паузе (из `churn_candidates`), отвечает на ответы.

**Для гостей:**
- Подбор салона/мастера по городу, району, цене, времени (как ProAI на сайте) — со ссылками на анкеты.

**Передача человеку:** жалобы, спорные оплаты, «позовите менеджера» → уведомление администратору (WhatsApp/Telegram) + метка в журнале.

### Правила бота
- Только массаж и SPA; на запросы интимного характера — вежливый отказ.
- Не выдумывает цены и наличие — только из данных API.
- Языки: русский, казахский, английский (по языку собеседника).
- Логирование всех диалогов (для качества и обучения), хранение по политике конфиденциальности сайта.

### Технически
- Сервис **probody-bot**: webhook Meta Cloud API → LLM (Claude через API или текущий OpenAI) с инструментами из Части 1 (+ отдельные write-инструменты только для бота: «создать черновик анкеты», «ссылка на оплату» — с ограничениями).
- Хранилище диалогов и состояний (Postgres/Redis).
- Админка: просмотр диалогов, статистика (сколько регистраций и оплат пришло из бота).

### Метрики
Ответ ≤ 1 мин 24/7 · конверсия «диалог → регистрация» · «регистрация → оплата» · возвращённые анкеты из паузы · доля переданных человеку.

### Этапы
1. Номер + WhatsApp Cloud API + webhook, бот отвечает по FAQ и ценам.
2. Подключение данных (статус анкеты по номеру, реактивация).
3. Помощь с регистрацией и оплатой.
4. Кейс для личного бренда и основа продукта **maxx.kz**.
